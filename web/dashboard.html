Finish your router setup

  1. Reserve Pocket DNS's IP in your router's DHCP settings.
  2. Set your router's LAN / DHCP DNS server to this address.
  3. Reconnect your devices or renew their network lease.

If two DNS fields are required, use the Pocket DNS address in both where supported. A public secondary can bypass filtering. Configure IPv6 DNS too, or clients may bypass it. Browser secure DNS, VPNs and hardcoded DNS can also bypass local filtering. DNS blocking cannot remove every ad, including ads delivered from the same domain as content.

Seeing only your router in Devices? Configure it to advertise Pocket DNS directly through DHCP instead of proxying all queries.

Device profiles

Add a rule

Rules include subdomains. Allow rules take priority. Changes clear the device cache immediately; clients may keep earlier answers until their TTL expires. Up to 200 rules per list, within 8 KB of combined domain storage.

Recovery
New firmware is confirmed after startup checks. A reset or crash before confirmation lets the bootloader return to the previous valid version.
Previous firmware must exist and be marked valid. Restore settings separately if needed. Hold BOOT for 8 seconds during normal operation to reset passwords, Wi-Fi and settings while keeping the blocklists.
About this device
Open source firmware based on M-Abozaid/esp32-c3-adblock. Balanced data: StevenBlack + HaGeZi Light. Strict adds HaGeZi Pro Mini rules. Firmware and blocklist licensing details are included in the build pack.
