A complete offline installer for ESP32-WROOM-32 and ESP32-S3. No Arduino IDE required.

01Plug in with a USB data cable. Close other serial monitors.
02Detect the board and install. Chip and flash size are selected automatically.
03Join the setup Wi-Fi. Follow the wizard, then set your router DNS.

Install Pocket DNS

Use desktop Chrome or Edge. On your WROOM-32, select the Silicon Labs / CP210x COM port. Only ESP32 and ESP32-S3 with 4 MB or more regular quad/SPI flash are supported. Octal-flash boards need a different build.

Connection help & install log

If detection fails, hold BOOT, press RESET, release RESET, then release BOOT when connected. Try a known USB data cable and another USB port. CP210x boards may need the Silicon Labs VCP driver. For S3 use the board's USB data port; a USB port intended for power alone will not work. Keep the device powered during installation.

Factory images and flashing libraries are embedded in this file. No external scripts, account or online flash service. Open source notices are in the build pack.
